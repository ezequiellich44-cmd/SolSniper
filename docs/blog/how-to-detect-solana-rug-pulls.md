# How to Detect Solana Rug Pulls in 2024

Rug pulls are the biggest problem in Solana trading. Every day, thousands of traders lose their money to scams. This guide shows you how to protect yourself.

## What is a Rug Pull?

A rug pull happens when a token developer:
1. Creates a token
2. Adds liquidity
3. Gets people to buy
4. Removes all liquidity
5. Disappears with the money

## How to Detect Rug Pulls

### 1. Check Mint Authority
If the dev can mint more tokens, they can dump on you. Always check if mint authority is disabled.

### 2. Check Freeze Authority
If the dev can freeze your wallet, you can't sell. Always check if freeze authority is disabled.

### 3. Check Holder Concentration
If one wallet holds more than 30% of supply, it's a red flag.

### 4. Check Liquidity
If liquidity is low, you might not be able to sell when you want.
